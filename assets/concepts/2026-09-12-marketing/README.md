# Video Subtitle Remover marketing concepts

This folder preserves the visual source material reviewed during the v3.42.0 marketing pass.

## Selected direction

The production mark stays unchanged. Its blue frame, diagonal removal slash, and subtitle bars remain recognizable at small sizes and fit the product better than the earlier redesign studies.

The `demo-media` folder contains the approved alpine interview source used to create realistic product screenshots. The source contains no text or branding. Subtitle overlays are added separately so the removal workflow can be shown honestly.

`packaged-app-proof.png` was captured from the rebuilt NVIDIA executable on an isolated Windows desktop. It is also the source for the primary README screenshot and the repository social preview.

## Archived studies

The `preexisting-redesign-studies` folder preserves all earlier v4 and v5 screen concepts. They are references only. They must not be presented as screenshots of the shipped application.

The `brand-reference` folder preserves the production icon and master mark that were reviewed for this pass.
