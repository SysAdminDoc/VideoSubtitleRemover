# Brand review

## Decision

Keep the production mark.

The blue frame reads as video or image framing. The white subtitle bars and diagonal removal stroke explain the product without a word. The silhouette stays recognizable at 16, 32, and 64 pixels, and the dark rounded-square container fits the shipped Windows interface.

## Asset checks

| Asset | Size | Pixel format | Alpha range | Use |
|---|---:|---|---|---|
| `icon.png` | 512 x 512 | RGBA | 0 to 255 | Application and README icon |
| `assets/branding/vsr-pro-mark-master.png` | 1024 x 1024 | RGBA | 0 to 255 | Master raster mark |

Both assets have real transparent pixels rather than a painted checkerboard or solid backdrop. The master has enough resolution for store and social layouts. The 512-pixel production icon is already appropriate for the application bundle.

## Rejected direction

The archived v4 and v5 interface studies are useful layout references, but they are not shipped screens. None of them provides a stronger mark than the current frame-and-removal symbol, so the brand stays consistent for this release.
